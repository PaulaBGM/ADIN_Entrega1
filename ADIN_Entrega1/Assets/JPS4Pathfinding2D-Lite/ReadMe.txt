
========= JPS4+ Lite 2D Grid Pathfinding =========

JPS4+ Lite 2D Grid Pathfinding is a free, single-threaded pathfinding solution tailored for 2D grids that generates paths dynamically.
This stands out from other 2D pathing solutions because it implements Jump Point Search Pathfinding in 4-connected Grids (Johannes Baum 2025).
For dense maps, JPS4 can drastically outperform A* by reducing the search space to remove unnecessary node expansions.

This is the Lite version. The full version — JPS4+ 2D Grid Pathfinding — is available on the Unity Asset Store:
  https://assetstore.unity.com/packages/slug/jps4-2d-grid-pathfinding-355438
The full version provides multithreaded, highly optimized, and Burst-compatible implementations of every algorithm included here.
